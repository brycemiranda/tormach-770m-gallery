# Photos go here — organized per machine

Create a folder per machine and drop photos in:

```
images/
  440/
    workholding/...
    toolholding/...
    endmills/...
    measuring/...
  770/
    workholding/...
    toolholding/...
    endmills/...
    measuring/...
    other/...
  8l/
    chucks/...
    toolholding/...
    turningtools/...
    measuring/...
```

Then in `data.js`, set that item's (or End Mill/Turning Tool family's)
`photo` field to the path **relative to the machine's folder**, e.g.:

```js
photo: "workholding/smw-vise.jpg"     // -> images/770/workholding/smw-vise.jpg
photo: "endmills/flat-hss.jpg"        // -> images/770/endmills/flat-hss.jpg (one photo per family is enough)
```

Tips:
- Landscape ~4:3, shot on a clean/neutral background.
- Keep filenames lowercase with dashes: `cylindrical-vise.jpg`.
- JPG or PNG both work. Aim for < 500 KB each so the page loads fast on phones.
- Leave `photo: ""` on any item and a blueprint placeholder is drawn automatically — no broken images while you're still collecting photos.
